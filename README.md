# Just for Toey 💙

เว็บเซอร์ไพรส์ส่วนตัว (HTML + CSS + JavaScript ล้วน ไม่มีเฟรมเวิร์ก ไม่มีฐานข้อมูล) เปิดบนมือถือเป็นหลัก

**หน้าต่าง ๆ:** ต้อนรับ · หน้าแรก · ความทรงจำ (แกลเลอรี) · เซอร์ไพรส์ (กล่องของขวัญ) · เพลง (YouTube) · จดหมาย · ความลับซ่อนอยู่ 3 จุด

## โครงสร้างไฟล์
```
index.html          โครงหน้าเว็บ
css/style.css       หน้าตา
js/app.js           เมนู/การสลับหน้า
js/gallery.js       แกลเลอรี + เลือกรูปจากเครื่อง
js/gift.js          กล่องของขวัญ
js/letter.js        จดหมาย
js/easter.js        ความลับที่ซ่อนอยู่
js/music.js         เพลง YouTube
data/content.js     ★ ไฟล์ที่คุณแก้: ข้อความ สี รูป เพลง จดหมาย (มีคอมเมนต์บอกทุกจุด)
assets/images/      รูปถาวร (ตอนนี้เป็นรูปวาดตัวอย่าง 3 รูป ลบแล้วใส่ของคุณ)
tests/              ชุดทดสอบ (ไม่ต้องอัปโหลดขึ้นเว็บก็ได้)
```

## เปิดดูในเครื่อง
ดับเบิลคลิก `index.html` ก็เปิดได้ แต่เบราว์เซอร์บางตัวจำกัดการเก็บรูป (IndexedDB) เมื่อเปิดแบบไฟล์ ถ้าอยากทดสอบให้ครบ ให้รันเซิร์ฟเวอร์ในโฟลเดอร์นี้: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## ปรับแต่ง: แก้อะไร ที่ไหน
| อยากเปลี่ยน | แก้ที่ | ใครเห็น |
|---|---|---|
| ชื่อเล่น, ข้อความต้อนรับ, สีหลัก, ชื่อเมนู | `data/content.js` ส่วน 1–5 | ทุกคน (หลังอัปโหลดใหม่) |
| รูปในแกลเลอรี + คำบรรยาย/วันที่ | ใส่ไฟล์ใน `assets/images/` + แก้ `gallery` | ทุกคน (หลังอัปโหลดใหม่) |
| ข้อความในกล่องของขวัญ | `gift` | ทุกคน |
| จดหมาย | `letter` | ทุกคน |
| ข้อความความลับ/แมว | `easter` | ทุกคน |
| เพลง (ชื่อ ศิลปิน โน้ต ลิงก์) | `music` | ทุกคน |
| รูปที่กด “เลือกรูปจากเครื่อง” | ในหน้าเว็บ | **เฉพาะเบราว์เซอร์เครื่องนั้น** ไม่ถาวร ไม่ขึ้นบนเครื่องเตย |

เว็บบน GitHub Pages แก้ไฟล์ตัวเองจากหน้าเว็บไม่ได้ (ไม่มี backend) การเปลี่ยนแปลงถาวรต้องแก้ไฟล์แล้วอัปโหลดใหม่เสมอ

**วิธีใส่รูปถาวร:** 1) ตั้งชื่อไฟล์เป็นอังกฤษ/ตัวเลข เช่น `trip1.jpg` (แนะนำย่อให้ไม่เกิน ~500 KB) แล้วใส่ใน `assets/images/` 2) เพิ่มบรรทัด `{ src: "assets/images/trip1.jpg", title: "...", caption: "...", date: "...", alt: "อธิบายรูปสั้น ๆ" }` ใน `gallery.photos` 3) `src` ต้องตรงกับชื่อไฟล์เป๊ะ รวมตัวพิมพ์เล็ก-ใหญ่และนามสกุล (`.jpg` ≠ `.JPG`) 4) ลบรูป = ลบบรรทัด (และไฟล์) 5) อัปโหลดใหม่ ถ้าอยากเอารูปที่เลือกจากมือถือไปใส่ถาวร ให้ส่งไฟล์รูปเข้าคอมแล้วทำตามข้อ 1–5

**เพลง:** ก๊อปลิงก์ YouTube ปกติมาใส่ `url` (รับ `watch?v=`, `youtu.be/`, `shorts/`) เว็บจะไม่เล่นเองตอนเปิดหน้า และจะโหลดวิดีโอจาก YouTube ก็ต่อเมื่อกด “เล่นที่นี่” บางวิดีโอเจ้าของปิดไม่ให้ฝัง ถ้าเล่นไม่ได้ให้กด “เปิดใน YouTube” เว็บนี้ไม่ดาวน์โหลดหรือก๊อปเพลงใด ๆ ตัวอย่างทั้ง 3 เพลงเป็นแค่ตัวอย่าง

**ความลับ:** ดาวดวงเล็กหน้าแรก (แตะ 5 ครั้งติด) · แมวในหน้าเซอร์ไพรส์ · หัวใจท้ายจดหมาย ไม่มีเนื้อหาสำคัญซ่อนอยู่ในนี้ ล้างได้ด้วยปุ่ม “เริ่มค้นหาใหม่” ที่หน้าแรก

## เผยแพร่บน GitHub Pages
1. สมัคร/เข้า github.com → กด **New repository** → ตั้งชื่อ เช่น `just-for-toey` → เลือก **Public** (Pages ฟรีต้องใช้ Public ยกเว้นบัญชีแบบเสียเงิน) → Create
2. กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ *ข้างใน* `just-for-toey` ทั้งหมดขึ้นไป (ให้ `index.html` อยู่ชั้นนอกสุดของ repo) → **Commit changes**
3. ไป **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, โฟลเดอร์ `/ (root)` → **Save**
4. รอ 1–3 นาที รีเฟรชหน้า Pages จะเห็นลิงก์ `https://ชื่อผู้ใช้.github.io/just-for-toey/`
5. เปิดลิงก์ในมือถือ ลองกดครบทุกหน้า
6. แก้ไฟล์ภายหลัง: เปิดไฟล์ใน GitHub → ไอคอนดินสอ → แก้ → Commit หรือ Add file → Upload files (ไฟล์ชื่อซ้ำจะถูกแทนที่) แล้วรอ 1–3 นาที

เว็บใช้พาธแบบ relative ทั้งหมด จึงทำงานใต้ `/ชื่อrepo/` ได้ ผมทดสอบแบบนี้แล้ว แต่ยังไม่ได้ลองบน GitHub จริง เพราะที่ผมทำงานต่ออินเทอร์เน็ตหรือ GitHub ไม่ได้

## ✅ เช็กความเป็นส่วนตัวก่อนเผยแพร่
1. แทนที่รูปตัวอย่างทั้งหมดด้วยรูปที่คุณสบายใจให้คนอื่นเห็น
2. อ่านข้อความ/คำบรรยายทุกอัน อย่าใส่ข้อมูลส่วนตัว (ที่อยู่ เบอร์ ที่เรียน/ที่ทำงาน)
3. ตรวจว่า repo และเว็บเป็น Public หรือไม่ — **ทุกไฟล์ใน repo Public ใครก็เปิด/ดาวน์โหลดได้** ลิงก์ที่เดายากไม่ใช่ความปลอดภัย
4. อย่าอัปโหลดรูปส่วนตัว/อ่อนไหว
5. เว็บนี้ไม่มีระบบรหัสผ่าน (รหัสฝั่งเบราว์เซอร์ป้องกันอะไรจริงไม่ได้ จึงไม่ทำให้) ถ้าต้องการจำกัดคนเข้าถึงจริง ๆ ต้องใช้โฮสติ้งที่มีระบบล็อกอินฝั่งเซิร์ฟเวอร์ (เช่น Cloudflare Access หรือบริการแชร์ไฟล์แบบเชิญเฉพาะคน) ไม่ใช่ GitHub Pages อย่างเดียว

ไม่มีการเก็บข้อมูลผู้ใช้ ไม่มีแอนะลิติกส์ ไม่มีสคริปต์ภายนอก (ติดต่อ YouTube เฉพาะตอนกดเล่นเพลง)

## แก้ปัญหา
- **รูปไม่ขึ้น / ขึ้น “ไม่พบรูป”**: ชื่อไฟล์ใน `src` ไม่ตรงกับไฟล์จริง (ตัวพิมพ์เล็ก-ใหญ่, นามสกุล, ช่องว่าง) หรือยังไม่ได้อัปโหลดรูป
- **เว็บขึ้นแต่หน้าไม่ทำงาน/ข้อความหาย**: `data/content.js` มีเครื่องหมายหาย (ลืมคอมมา `,` หรือเครื่องหมาย `"`) ลองก๊อปไฟล์เดิมมาเทียบ
- **เว็บ 404 บน GitHub**: `index.html` ต้องอยู่ชั้นนอกสุดของ repo และ Pages ต้องตั้งเป็น branch `main` / root รอสักครู่หลังตั้งค่า
- **แก้แล้วไม่เปลี่ยน**: รอ 1–3 นาที แล้วรีเฟรชแรง ๆ (หรือเปิดแท็บส่วนตัว)
- **เพลงเล่นในเว็บไม่ได้**: เจ้าของวิดีโอปิดการฝัง ใช้ปุ่ม “เปิดใน YouTube”
- **เลือกรูปจากมือถือแล้วไม่ได้**: รองรับ JPG/PNG/WebP/GIF ไม่เกิน 15 MB ต่อรูป ไม่รองรับ HEIC (iPhone ตั้งกล้องเป็น “Most Compatible” หรือแปลงเป็น JPG ก่อน)

## ข้อจำกัดที่ทราบ
- รูปที่เลือกจากเครื่องเก็บในเบราว์เซอร์ อาจหายถ้าล้างข้อมูลเบราว์เซอร์/โหมดส่วนตัว และไม่ไปปรากฏบนเครื่องคนอื่น GIF ที่เลือกจากเครื่องจะกลายเป็นภาพนิ่ง
- ทดสอบด้วยเบราว์เซอร์จำลองมือถือ (Chromium) เท่านั้น ยังไม่ได้ลองบนมือถือจริง/Safari/Firefox
- ตัวอย่างลิงก์ YouTube ฝังได้หรือไม่ขึ้นกับเจ้าของวิดีโอ ผมตรวจไม่ได้เพราะที่ผมทำงานออกเน็ตไม่ได้
